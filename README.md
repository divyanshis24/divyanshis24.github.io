# divyanshis24.github.io

Personal portfolio — Divyanshi Sharma.

A single static page: `index.html`. No build step, no dependencies.
Fonts load from Google Fonts; everything else is inline.

## Local preview

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000

## Deploy

Hosted on GitHub Pages from the `main` branch root.
Push to `main` and the live site updates within a minute or two.

```bash
git add -A && git commit -m "Update portfolio" && git push
```
